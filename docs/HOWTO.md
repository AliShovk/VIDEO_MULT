# Новая серия за 30 минут

## 0. Подготовка

```bash
python -m pip install -r requirements.txt
ffmpeg -version   # должен отвечать
```

Проверьте `settings.json`: прокси для Edge TTS (или `"engine": "piper"`), шрифты, палитра.

## 1. Сценарий — `lines.txt`

6–8 реплик, каждая 8–14 слов. Формула, которая работает:

1. **Хук** — вопрос или цифра, без разгона. «Что, если ты станешь размером с муравья?»
2. **Первый факт** с числом и бытовым сравнением.
3. **Второй факт** — контринтуитивный.
4. **Третий факт** — про цену/риск.
5. **Разворот** — «зато…», чтобы не оставить зрителя в минусе.
6. **Итог** одной фразой.
7. **Вопрос в зал** — для комментариев.

Проверка: прочитайте вслух. Если фраза не влезает в 4 секунды — она длинная.

## 2. Озвучка

```bash
python tools/make_voice.py episodes/<slug>/lines.txt
```

Скрипт кладёт `voice/line_XX.wav` и `voice/lines.json` (`id, text, file, dur`). Все тайминги
эпизода считаются от этого файла — поэтому озвучка всегда делается **до** правки сцен.

Частые проблемы:

- `NoAudioReceived` — нет прокси/троттлинг. Проверьте `curl -x http://127.0.0.1:10809 https://api.ipify.org`,
  скрипт сам ретраит 6 раз.
- Голос кажется медленным — поднимайте `rate` до `+35%`, но не выше.
- Нужен женский — `--voice ru-RU-SvetlanaNeural`.

## 3. Сцены

Скопируйте папку эпизода:

```bash
cp -r episodes/ant_scale_02 episodes/<slug>
```

В `ep_ant.py`:

- `SCENE_FN` — список функций сцен, по одной на реплику (порядок = порядок реплик);
- `CAMS` — камера на каждую сцену: `Cam(cx, cy, zoom)`. `cy ≈ 1250–1300` держит героя в нижней
  половине, освобождая верх под титр и графику;
- `CAPS` — короткие титры (4–7 слов), не дублируют речь дословно;
- `STICK` — стикеры-акценты: `(текст, доля_сцены, цвет)`; доля 0.45–0.6 — «на середине реплики».

Каждая сцена — функция `sceneN(d, t)`; состояние не хранится, поэтому любой кадр можно
отрендерить отдельно и проверить.

## 4. Реквизит и хват

```python
joints = F.hero(d, x, GROUND, h, pose)      # вернёт hands/head/feet
hands = joints["hands"]
F.crumb(d, x + 10, min(h[1] for h in hands) - 100, 320)   # предмет
F.circle(d, hands[0], 13, SKIN_S, INK, 5)                 # кисти поверх предмета
```

Порядок «предмет → кисти поверх» обязателен: у чиби-пропорций поднятые руки попадают ровно под
макушку, и предмет читается как шапка.

## 5. Предпросмотр и рендер

```bash
python episodes/<slug>/ep_ant.py --preview      # preview/full_*.png
```

Смотрите **каждый** кадр: позы, перекрытия, читаемость титров. Правьте и повторяйте.

```bash
python episodes/<slug>/ep_ant.py --render       # frames/f0000.png…
python tools/build.py                           # out.mp4 + gif + contact_sheet.jpg
```

Рендер можно прерывать: повторный запуск пропустит уже готовые кадры.

## 6. Приёмка

- `ffprobe out.mp4` — длительность, 1080×1920, `yuv420p`, число кадров.
- `ffmpeg -i out.mp4 -af ebur128=peak=true -f null -` — интегральная громкость ≈ −14 LUFS.
- Вынуть 3–4 кадра из готового файла (`ffmpeg -ss 6 -i out.mp4 -frames:v 1`) и посмотреть глазами.
- Проверить, что каждая реплика звучит и титр не уезжает: тайминги берутся из `lines.json`,
  но ручные `delay` в стикерах надо пересчитать после смены голоса.

## Чек-лист перед публикацией

- [ ] Хук укладывается в первые 2 секунды.
- [ ] В каждой сцене есть движение (камера или персонаж).
- [ ] Титры не ниже `y=1690` и не перекрывают героя.
- [ ] Эндкард не закрывает лицо.
- [ ] Громкость −14 LUFS, пик ≤ −1.5 dBTP.
- [ ] Все цифры в кадре объяснены в речи.
